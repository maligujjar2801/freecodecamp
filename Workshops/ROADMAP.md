# Python Workshop Roadmap

![Python workshop roadmap](python-workshop-roadmap.png)

## What this folder is for

This directory is a growing collection of focused Python workshops. Each workshop groups related code with learning notes so the repository can be used as a practical reference—not just a collection of finished exercises.

## Learning path

Follow the stages in order when learning from the beginning. If you already understand a topic, skim its notes and try the code challenge before moving on.

1. **Python Basics** — build confidence with syntax, variables, input/output, types, and simple programs.
2. **Collections** — work with lists, tuples, sets, and dictionaries, and learn when each is useful.
3. **Object-Oriented Programming** — model concepts with classes, objects, attributes, methods, and encapsulation.
4. **Validation and Regular Expressions** — validate input, inspect strings, and use patterns to identify formats and malformed data.
5. **Functions and Configuration** — break work into reusable functions and practise handling configuration and predictable program behaviour.
6. **Data Structures** — implement and reason about structures such as linked lists, including their operations and trade-offs.
7. **Recursion** — solve problems using a base case and smaller recursive calls.

## Recommended coding flow

1. **Read the notes.** Identify the purpose, terminology, and syntax.
2. **Trace the code.** Predict what important lines will do before running them.
3. **Experiment.** Change one input or condition at a time and observe the result.
4. **Build from memory.** Recreate the core behaviour without copying line by line.
5. **Test edge cases.** Try empty input, unexpected values, duplicates, or missing keys where relevant.
6. **Review and explain.** Record what was confusing, why the approach works, and what could improve.
7. **Commit a focused change.** Keep changes small and use a descriptive commit message.

## Folder conventions

- Keep Python exercise files in the folder for their main topic.
- Keep explanatory notes beside the matching script, using a clear notes filename.
- Use each topic folder's README for a short overview and instructions.
- Preserve original exercise code when reorganising; document issues rather than silently changing intended behaviour.

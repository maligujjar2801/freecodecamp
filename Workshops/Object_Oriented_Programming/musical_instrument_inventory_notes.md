# Workshop Notes — Musical Instrument Class

## Goal
Model musical instruments using a Python class and create individual objects.

## Concepts
- A **class** defines the attributes and behavior shared by objects.
- `__init__` initializes a new object.
- `self` refers to the current instance.
- `self.name` and `self.instrument_type` are instance attributes.
- `play()` demonstrates a method that prints a message.
- `get_fact()` returns a string to the caller.

## Walkthrough
1. Define `MusicalInstrument`.
2. Save the instrument's name and family in each instance.
3. Create an oboe and a trumpet object.
4. Call `play()` on the oboe and print the fact returned by `get_fact()`.

## Expected behavior
The program prints a friendly message about the oboe and explains that it belongs to the woodwind family.

## Practice
Create a third instrument object, call both methods, and compare how the same class supports different data.
